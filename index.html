Catch speech-model regressions before your users do.

Every new model version, inference change or API update is replayed against the same hard, real-world Indian audio: Hinglish code-mix, OTPs, rupee amounts, names, 6 languages, street noise. Old model vs new model, same audio, side by side. If anything gets worse, the release is blocked.

Tip: write Indic text in its native script (हिंदी, தமிழ்…). Saaras transcribes in native script, so Roman-script Hinglish makes WER meaningless; the LLM judge still scores meaning.

Put it in CI

# .github/workflows/kasauti.yml  — runs on every PR, exits 1 on regression
python harness.py --local --base saaras:v3 --cand saaras:v4 --snr 10 --threshold 0.05
# or against this deployment:
python harness.py --url https://<this-site> --snr 10
# prints the same per-category table as above, writes kasauti_report.json,
# exit 0 = PASS, exit 1 = FAIL (release blocked)

Why same-audio A/B: both models hear byte-identical noisy audio (fixed seed), so a delta is the model, not the input. Why an LLM judge: WER says “₹2,450” ≠ “2450 rupees”; the judge scores meaning and flags wrong numbers, names and amounts. Built on Sarvam Bulbul, Saaras and Sarvam LLM.
